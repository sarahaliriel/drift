# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. This repository does not currently have a configured private security reporting channel, so it does not yet provide an operational way to submit a report. Before presenting this policy as operational, maintainers must add a verified private contact method or enable GitHub private vulnerability reporting.

Do not include secrets, credentials, or sensitive personal data in public reports. No response or remediation timeline has been established.

## Supported versions

Drift is under active development and has no published release or supported-version policy yet. The current repository state is the only development target; this is not a production support commitment.
